# Part 1: Learning Journey Plan

## Source Language

Python

## Target Language

Java

## Learning Goal

I am already comfortable with Python and want to learn Java so that I can understand object-oriented programming more deeply, write strongly typed applications, and build structured command-line applications.

My main learning goals are:

1. Understand the key differences between Python and Java, including syntax, type systems, object-oriented programming, and program structure.
2. Learn how to use Java's core features, including classes, objects, methods, collections, exception handling, and file input/output.
3. Build a small command-line Task Manager application in Java to apply the concepts I have learned.

---

# Phase 1: Java Fundamentals and Core Syntax

## Prerequisites

I should be comfortable with basic programming concepts such as:

* Variables and data types
* Conditional statements
* Loops
* Functions and methods
* Basic input and output
* Basic debugging

## Learning Steps

1. Learn how Java programs are structured and understand how the Java Development Kit (JDK), Java Virtual Machine (JVM), and Java compiler work together.
2. Learn Java's primitive data types and reference types and compare them with Python's dynamic typing.
3. Learn Java variables, operators, conditional statements, and loops.
4. Learn how Java methods work, including parameters, return types, and method overloading.
5. Learn how to receive user input using `Scanner` and display output using `System.out.println()`.

## Verification Activities

* Write a Java program that asks a user for their name and age.
* Create a program that determines whether a number is even or odd.
* Write a program that uses a loop to calculate the sum of numbers.
* Explain the difference between Python variables and Java variables.
* Convert a simple Python program into Java without copying the code directly.

---

# Phase 2: Object-Oriented Programming in Java

## Prerequisites

I should understand:

* Variables and data types
* Methods
* Conditional logic
* Loops

## Learning Steps

1. Learn how to create Java classes and objects.
2. Understand constructors and how they initialize objects.
3. Learn encapsulation using access modifiers such as `private` and `public`.
4. Learn inheritance, interfaces, and polymorphism.
5. Understand how Java's object-oriented approach compares with Python's class system.

## Verification Activities

* Create a `Task` class with properties such as title, description, and completion status.
* Create objects from the `Task` class.
* Add methods that allow tasks to be marked as completed.
* Explain the difference between a class and an object.
* Explain how encapsulation in Java compares with Python.

---

# Phase 3: Collections, Exceptions, and File Handling

## Prerequisites

I should understand:

* Classes and objects
* Methods
* Basic Java syntax

## Learning Steps

1. Learn how to use arrays and the `ArrayList` collection.
2. Learn how to iterate through collections using loops and enhanced `for` loops.
3. Learn Java exception handling using `try`, `catch`, and `finally`.
4. Learn how to read and write data to files.
5. Learn how to organize Java code into packages and multiple classes.

## Verification Activities

* Store multiple `Task` objects in an `ArrayList`.
* Create a program that handles invalid user input.
* Save tasks to a file.
* Load saved tasks when the program starts.
* Explain when to use an array versus an `ArrayList`.

---

# Phase 4: Build the Java Task Manager

## Prerequisites

I should understand:

* Java fundamentals
* Classes and objects
* Methods
* Collections
* Exception handling
* Basic file handling

## Learning Steps

1. Design the application's requirements and user interaction flow.
2. Create a `Task` class to represent individual tasks.
3. Create a task management class responsible for adding, viewing, updating, and deleting tasks.
4. Create a command-line menu that allows users to interact with the application.
5. Add file storage so that tasks can be saved and loaded between program executions.

## Verification Activities

* Demonstrate that a user can add a task.
* Demonstrate that a user can view all tasks.
* Demonstrate that a user can mark a task as completed.
* Demonstrate that a user can delete a task.
* Restart the application and verify that saved tasks are still available.
* Review the final project for Java best practices and identify any Python habits that remain in the code.

---

# Final Learning Outcome

By the end of this learning journey, I should be able to:

* Explain the major differences between Python and Java.
* Write basic Java programs independently.
* Create and use Java classes and objects.
* Use Java collections and exception handling.
* Read and write data using Java file handling.
* Structure a small Java application using multiple classes.
* Build and explain a functional command-line Task Manager.
* Identify Python programming habits that may not be appropriate in Java.
* Continue learning Java independently using documentation, practice, and AI-assisted learning.
