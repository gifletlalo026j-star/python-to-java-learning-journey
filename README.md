# Python to Java Learning Journey

## Overview

This repository documents my journey of learning Java as a Python programmer. The project follows a structured AI-assisted learning approach that focuses on understanding the differences between Python and Java, applying structured prompting techniques, and building a practical Java application.

The purpose of this project is to demonstrate how AI can be used as a learning tool while developing practical programming skills.

## Source Language

Python

## Target Language

Java

## Learning Goals

My main learning goals are:

1. Understand the key differences between Python and Java.
2. Learn Java syntax, data types, methods, classes, objects, collections, exception handling, and file handling.
3. Understand object-oriented programming in Java.
4. Apply my Java knowledge by building a command-line Task Manager.
5. Learn how to use structured AI prompts to support my programming education.

## Learning Journey

### Part 1: Learning Journey Plan

The learning plan is divided into four phases:

* Java fundamentals and core syntax
* Object-oriented programming
* Collections, exception handling, and file handling
* Building a Java Task Manager

### Part 2: Four-Step Prompting Strategy

The project applies four structured prompting techniques:

1. Conceptual Understanding
2. Step-by-Step Breakdown
3. Guided Implementation
4. Understanding Verification

### Part 3: Advanced Prompting Techniques

The project also explores advanced techniques such as:

* Using context effectively
* Promoting deep understanding
* Learning through teaching
* Using AI as a programming tutor

### Part 4: Mini-Project

The final project is a command-line Java Task Manager.

The application allows users to:

* Add tasks
* View tasks
* Mark tasks as completed
* Delete tasks
* Save tasks to a file
* Load tasks when the application starts

## Final Project

The Java Task Manager demonstrates my understanding of Java programming concepts learned throughout this learning journey.

The application uses object-oriented programming to represent tasks and manage a collection of tasks. It also uses file handling to save and load task information.

## Learning Reflection

Throughout this project, I used my existing Python knowledge as a foundation for learning Java. Comparing the two languages helped me understand differences in syntax, type systems, object-oriented programming, and application structure.

The project also helped me understand how AI can be used not only to generate code but also to explain concepts, provide guidance, verify understanding, and help identify areas for further learning.
